# VibeCut 商业化策略

## 主方向：AI全栈工程师实战培训课程
以 VibeCut 完整产品为教学案例的 AI 应用开发培训。

## 课程体系
- 初级班 (2周): "用AI理解视频" — Embedding + RAG 核心概念
- 中级班 (3周): "AI驱动的视频剪辑" — Agent编排 + 精切引擎
- 高级班 (3周): "Agent化架构设计" — LangGraph + Agentic RAG + HITL

## 核心差异化
- 不是 demo 是产品 (15000+行代码)
- 4个AI模型协同工作 (BGE+Whisper+DeepSeek+MiMo)
- 完整全栈覆盖 (语言→框架→模型→产品)
- 33篇知识库笔记作为教材
- 架构演化史可追溯 (v0.1→v1.0)
- 市场上唯一以"AI理解视频并辅助决策"为卖点的教学项目

## 变现方式
- 录播课程 ¥999-1,999
- 直播训练营 ¥4,999-6,999
- 企业内训 ¥3-5万/场
- 高校合作课程 (学期制)
- 知识库订阅 ¥199/年

## 执行阶段
- Phase 1 (1-3个月): 课程内容就绪, 招募内测学员
- Phase 2 (3-6个月): 课程验证迭代, 开设初/中级班
- Phase 3 (6-12个月): 规模化, 三条产品线

**Why:** 三位一体策略中"商业"维度的具体落地。AI培训市场500万人才缺口, VibeCut作为教学案例具有独特壁垒。
**How to apply:** 课程开发与系统开发同步进行, 每个新功能既是产品进步也是教学内容。
