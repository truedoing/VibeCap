# 文本嵌入与语义向量

> 一句话讲清楚：把任意中文文本变成一串 768 个数字，两段文本的意思越接近，数字串就越相似。

## 是什么

**Embedding（嵌入）** 是把文字映射到高维向量空间的技术。一个句子变成一个固定长度的浮点数数组（比如 768 个 float32），这个数组就叫"向量"或"嵌入"。

```
"苏明玉站在办公室窗前" → BGE 模型 → [0.023, -0.451, 0.789, ..., 0.134]  (768个数字)
"明玉在公司里望着窗外"   → BGE 模型 → [0.019, -0.443, 0.795, ..., 0.141]  (相似!)
"今天天气真不错"         → BGE 模型 → [-0.832, 0.221, -0.156, ..., 0.667] (不相似)
```

两个向量的余弦相似度越接近 1，语义越接近。

## 为什么需要

VibeCut 的核心需求：**用户输入一句自然语言描述（"苏大强在老宅翻存折"），找到原剧中最匹配的视频片段。**

不能用关键词搜索——用户说的是"翻存折"，但 ASR 转写里可能是"找那个本子""存折在哪儿"。只有语义搜索能跨越措辞差异。

## 关键概念

### 1. 向量空间

- BGE-base-zh-v1.5 输出的向量维度是 **768**
- 每个维度没有直观含义，但整个向量的"方向"代表了语义
- 经过 **L2 归一化** 后，向量的模长为 1，此时 `dot(a, b)` = 余弦相似度

### 2. 余弦相似度

```python
# 两个归一化向量的内积 = 余弦相似度 ∈ [-1, 1]
similarity = np.dot(embedding_a, embedding_b)

# 1.0  = 完全相同
# 0.0  = 不相关
# -1.0 = 语义相反
```

### 3. sentence-transformers

一个 Python 库，封装了 HuggingFace Transformers 模型加载和推理。三行代码把一个句子变成向量：

```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer("BAAI/bge-base-zh-v1.5")
embedding = model.encode("你好世界")  # → shape (768,)
```

### 4. 批处理

对 N 个句子同时编码比逐个编码快 10-50 倍：

```python
embeddings = model.encode(texts, batch_size=32, show_progress_bar=True)
```

VibeCut 建索引时一次性编码 8000+ 条文本，批处理是必须的。

## 动手实验

```bash
pip install sentence-transformers numpy
python3 -c "
from sentence_transformers import SentenceTransformer
import numpy as np

model = SentenceTransformer('BAAI/bge-base-zh-v1.5')
a = model.encode('苏明玉站在办公室窗前')
b = model.encode('明玉在公司里望着窗外')
c = model.encode('今天天气真不错')

print(f'相似句: {np.dot(a, b):.3f}')   # 应该 > 0.7
print(f'不相关: {np.dot(a, c):.3f}')   # 应该 < 0.4
"
```

## 常见误区

- ❌ "768 个数字每个都有含义" → 没有，单个维度不可解释
- ❌ "距离越近越相似" → 用余弦相似度，不是欧氏距离
- ❌ "BGE 模型越大越好" → BGE-base (102M 参数) 对中文已经足够好
