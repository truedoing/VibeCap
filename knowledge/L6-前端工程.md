> VibeCut 的用户界面 — React 组件化 + 视频编辑引擎 + 实时流式交互

## 与其他层的关系

```
L6 前端工程
  │
  ├── 消费 L2 的 API ──→ HTTP REST + SSE 流式
  ├── 展示 L4 的检索结果 ──→ 搜索结果卡片 + 预览播放
  ├── 呈现 L5 的 Agent 进度 ──→ Agent Dashboard + 审批面板
  └── 集成 Elah 引擎 ──→ 浏览器端视频预览 + 时间轴编辑
```

## 前端核心能力

### 1. 三栏布局编剧台 (PlanningDesk)

- 口播素材 | 剪辑脚本 | AI 助手
- SSE 流式展示 Agent 生成进度
- 粗段/精切页签切换

### 2. 分镜台 (VibeEdit)

- Elah 多轨时间轴 (口播 2 轨 / 电视剧 4 轨)
- 代理视频 WebGL2 预览
- 精切 KEEP/CUT 可视化

### 3. AI 搜索面板 (ChatPanel)

- 多轮对话式搜索
- 搜索结果 + 剧集过滤
- 台词匹配 / 分镜推荐
