# 混合搜索策略

> 向量搜索能理解"语义"，关键词搜索能精确匹配"人名地名"，两者融合才是真正好用的搜索。

## 是什么

**混合搜索 = 向量语义搜索 + 关键词精确匹配，加权合并结果。**

纯向量搜索的问题：你搜"苏大强"，BGE 可能把"苏明玉""老苏"排在前面，因为语义接近，但"苏大强"三个字可能根本没出现在结果里。

纯关键词的问题：你搜"悲伤的告别场景"，ASR 文本里没有这六个字，但 VLM 画面描述里有很多类似场景。关键词搜不到。

混合搜索让两者互补。

## 为什么需要混合

```
场景 1: 精确人物/地点搜索
查询: "苏大强在老宅翻存折"
  → 关键词: "苏大强" "老宅" "存折" 直接匹配 ASR 文本 ✓
  → 语义:   理解"翻存折"就是"找东西"的行为 ✓

场景 2: 抽象情绪/氛围搜索
查询: "温馨的家庭团聚时刻"
  → 关键词: "温馨""家庭""团聚" 可能不在文本里 ✗
  → 语义:   理解抽象概念，匹配饭桌、笑声等场景 ✓
```

## 关键概念

### 1. n-gram 关键词评分

VibeCut 的 N-gram 加权算法（`server.py` 的 `_keyword_search`）：

```python
kws = {}
qlen = len(query)
for n in range(2, min(qlen + 1, 9)):    # 从2字到8字
    w = 3 ** (n - 2) if n <= 5 else 27   # 权重指数增长
    seen = set()
    for i in range(qlen - n + 1):
        kw = query[i:i+n]
        if kw not in seen:
            seen.add(kw)
            kws[kw] = max(kws.get(kw, 0), w)

# 完整查询作为最高权重关键词
if qlen > 4:
    kws[query] = 81  # 完整匹配权重最高
```

权重设计逻辑：
- 2-gram（双字）：权重 1 —— 随机匹配（"大强"也匹配"苏大强"但也会匹配"强大"）
- 3-gram（三字）：权重 3 —— 更可能是有意义词组
- 4-gram（四字）：权重 9 —— 很可能是完整的人名/地名
- 5-gram+：权重 27 —— 基本确定是精确匹配
- 完整查询：权重 81 —— 最佳匹配

**为什么用指数增长而不是线性？** 越长的连续匹配意味着越精确。四字短语"苏大强在"比两个字"苏大"精确得多，应该给指数级更高的权重。

### 2. 相邻片段合并

```python
# 匹配片段的前后相邻段也有匹配时，合并扩展上下文
if i > 0 and score_of(i-1) > 0:
    start = asr_list[i-1]["start"]
    text = asr_list[i-1]["text"] + " " + text
    merged += 1
if i+1 < len(asr_list) and score_of(i+1) > 0:
    end = asr_list[i+1]["end"]
    text += " " + asr_list[i+1]["text"]
    merged += 1

score += merged * 5  # 合并奖励
```

你搜"苏大强在老宅翻存折"，ASR 中可能分三句："苏大强站在老宅里"（句1）、"翻着抽屉找存折"（句2）、"嘴里念叨着什么"（句3）。合并后返回从句1到句3的完整片段，比只返回句2的中断片段有用得多。

### 3. 加权合并（0.7 语义 + 0.3 关键词）

```python
def _hybrid_search(query, limit=10):
    semantic_results = self._semantic_search(query, 30)
    keyword_results = self._keyword_search(query, 30)

    merged = {}
    # 语义得分归一化到 0-70
    max_s = max((r["score"] for r in semantic_results), default=1)
    for r in semantic_results:
        k = f"{r['ep']}_{r['start']:.0f}"
        merged[k] = {**r, "score": r["score"] / max_s * 70}

    # 关键词得分归一化到 0-30
    max_k = max((r["score"] for r in keyword_results), default=1)
    for r in keyword_results:
        k = f"{r['ep']}_{r['start']:.0f}"
        kw_score = r["score"] / max_k * 30
        if k in merged:
            merged[k]["score"] += kw_score  # 双命中 = 70 + 30 = 100
        else:
            merged[k] = {**r, "score": kw_score}

    return sorted(merged.values(), key=lambda x: -x["score"])[:limit]
```

权重的含义：
- 语义：70% —— 搜"苏大强"时也会找到"老苏""我大哥"（语义上指同一个人）
- 关键词：30% —— 精确字符匹配的加分
- 当同一位置语义和关键词都命中，得分 = 70 + 30 = 100（满分）

这 7:3 的比例是实践中调整出来的。如果关键词占比太高（比如 5:5），精确术语匹配会淹没语义相关性；如果关键词太低（比如 9:1），抽象查询会找不到明星名字这种精确匹配。

### 4. 口播模式的特殊合并

口播项目中 `_merge_results` 使用不同的权重分配：
- 关键词：0-40（`r["score"] / max_kw * 40`）
- 语义：0-60（`r["score"] / max_sem * 60`）

口播数据更依赖语义（guest 说话风格的口语化表述），稍降关键词的权重。

### 5. ASR 优先搜索（asr_first）

`_asr_first_search` 是电视剧专用的混合变体：
- **优先**：ASR 关键词精确匹配（加权 n-gram，得分 ×1.5）
- **兜底**：语义搜索补足，但语义结果降权 ×0.4
- **替换**：语义结果用 ASR 台词替换 VLM 描述文本

设计原因：电视剧剪辑时，用户通常想找"角色说了什么"，而不是"画面里有什么"。对话是剪辑的核心素材。

### 6. 深度搜索（deep）

`_deep_search` 是更激进的混合策略：

```
Query 扩展（LLM 生成 2-3 个不同角度搜索词）
  → 每个变体做 hybrid 搜索
  → 取并集（保留每个位置的最高分）
  → LLM 重排 Top-20
```

适合的场景：用户只给了模糊的分镜描述（"一个悲伤的离别场景"），需要从多个角度搜（"流泪的近景""车站告别""背影远去"），再由 LLM 从候选里挑最贴切的。

## 动手实验

1. **手写 n-gram 评分器**

```python
def ngram_score(query, text):
    score = 0
    qlen = len(query)
    for n in range(2, min(qlen + 1, 9)):
        w = 3 ** (n - 2) if n <= 5 else 27
        for i in range(qlen - n + 1):
            kw = query[i:i+n]
            score += text.count(kw) * w
    return score

print(ngram_score("苏大强在老宅", "苏大强站在老宅院子里翻存折"))  # 高
print(ngram_score("苏大强在老宅", "这是一段无关的对话"))        # 0
```

2. **实现简单的混合搜索**

```python
def simple_hybrid(query, documents, embeddings, query_emb):
    # 语义
    sem_scores = np.dot(embeddings, query_emb)
    # 关键词
    kw_scores = np.array([ngram_score(query, doc) for doc in documents])
    # 归一化合并 7:3
    sem_norm = sem_scores / sem_scores.max() * 70 if sem_scores.max() > 0 else 0
    kw_norm = kw_scores / kw_scores.max() * 30 if kw_scores.max() > 0 else 0
    final = sem_norm + kw_norm
    return np.argsort(final)[-10:][::-1]
```
