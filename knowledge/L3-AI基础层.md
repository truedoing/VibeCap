# L3: AI 基础层

> VibeCut 的"智能"来源 — 嵌入、语音识别、大语言模型、视觉语言模型

## 本层知识点

| 笔记 | 主题 | 难度 | 状态 |
|------|------|------|------|
| [[文本嵌入与语义向量]] | Embedding, BGE模型, sentence-transformers | 🟡 | ✅ |
| [[语音识别ASR]] | faster-whisper, CTranslate2, int8量化 | 🟡 | ✅ |
| [[大语言模型LLM]] | DeepSeek, Prompt Engineering, JSON Mode | 🟡 | ✅ |
| [[视觉语言模型VLM]] | MiMo v2.5, 多帧分析, 画面描述 | 🟡 | ✅ |
| [[模型部署与优化]] | CPU推理, mmap加载, 离线模式 | 🟡 | ✅ |

## 为什么这层是"核心"

AI 基础层是 VibeCut 区别于传统视频编辑软件的关键。没有这层，VibeCut 就是一个普通的 Web 剪辑工具。

**每个模型各司其职：**

```
视频素材
  │
  ├── 音频流 ──→ [[语音识别ASR|faster-whisper]] ──→ 文本 (说什么)
  │
  ├── 视频流 ──→ [[视觉语言模型VLM|MiMo VLM]] ──→ 描述 (画面是什么)
  │
  └── 两者结合 ──→ [[文本嵌入与语义向量|BGE Embedding]] ──→ 向量 (可搜索)
                       │
                       ▼
              [[大语言模型LLM|DeepSeek LLM]] ──→ 剪辑脚本 (怎么剪)
```

## 学习路径

```
起点: [[文本嵌入与语义向量]] — 最直观，能看到"文字变数字"
  │
  ▼
[[大语言模型LLM]] — 理解 Prompt Engineering 和 API 调用模式
  │
  ▼
[[语音识别ASR]] — 理解音频→文本的本地推理
  │
  ▼
[[视觉语言模型VLM]] — 理解多模态（文本+图片→文本）
```

| 概念 | 一句话 | 详见 |
