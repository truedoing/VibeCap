# L7: 前沿探索

> VibeCut 的未来方向 — Agentic RAG、多 Agent 协作、自我学习系统

## 本层知识点

| 笔记 | 主题 | 难度 | 状态 |
|------|------|------|------|
| [[Agentic-RAG]] | Agent 驱动的多轮检索与策略调整 | 🔴 | 📅 |
| [[多Agent协作]] | 不同剪辑风格的 Agent 分工协作 | 🔴 | 📅 |
| [[Agent自我学习]] | 偏好学习、反馈归因、跨任务迁移 | 🔴 | 📅 |

## 这些不是"未来幻想"

每项都有明确的学术基础和应用案例：

| 方向 | 学术基础 | 业界案例 |
|------|---------|---------|
| Agentic RAG | Self-RAG, CRAG 论文 | LangGraph + Tool Use |
| 多 Agent | Multi-Agent Debate, AutoGen | CrewAI, Microsoft AutoGen |
| 自我学习 | RLHF, DPO, Constitutional AI | ChatGPT 的 RLHF 训练 |

## 与其他层的关系

```
L5 (Agent系统) ──→ L7 (前沿探索)
                    │
                    ├── Agentic RAG: Agent + RAG 深度融合
                    ├── 多Agent: 从单 Agent 到 Agent 团队
                    └── 自我学习: 从固定策略到自适应策略
```

## 探索优先级

1. **Agentic RAG** — 最接近落地。ChatPanel 的自然升级
2. **自我学习** — 有反馈数据就能做。关键是要有数据回收闭环
3. **多 Agent 协作** — 最远。需要先有稳定的单 Agent 基础
