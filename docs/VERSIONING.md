# VibeCut 版本策略

## 格式: MAJOR.MINOR.PATCH (语义化版本)

| 变更类型 | 版本变化 | 示例 |
|---------|---------|------|
| Bug修复、文案调整、小修补 | PATCH: x.x.N → x.x.N+1 | 1.1.0 → 1.1.1 |
| 小功能新增、优化、重构 | MINOR: x.N.x → x.N+1.0 | 1.1.0 → 1.2.0 |
| 大模块、新能力、新系统 | MINOR: x.N.x → x.N+1.0 | 1.1.0 → 1.2.0 |
| 架构升级、破坏性变更、推翻重来 | MAJOR: N.x.x → N+1.0.0 | 1.x.x → 2.0.0 |
