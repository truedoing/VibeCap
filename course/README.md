# Agent 产品 · 端到端课程体系

> 课程是「三位一体」里 **商业（Business）维** 的产物。系统（VibeCut）驱动知识积累，知识积累支撑这门课，这门课反哺系统迭代方向。

## 课程主张

AI 时代对工程师的要求，从「**专且深**」转向「**广且高**」：

- **广**：覆盖 Agent 产品从想法到运营的全流程——融合产品经理、架构师、开发、运营。
- **高**：关键决策有判断高度，不纠结工具细节，纠结「**什么时候该用哪个工具**」。

不是"我会写代码"，是"我能端到端把一个 Agent 产品做出来、发出去、跑起来"。

## 课程坐标：生命周期 × 技能栈

两个正交维度，共同定位每一节课：

| 维度 | 是什么 | 装在哪 |
|---|---|---|
| **纵向 · 生命周期**（叙事主线） | 一个 Agent 产品从 ① 到 ⑥ 走一遍 | 本目录 `map.md` |
| **横向 · 技能栈**（血肉） | 语言 / 后端 / AI / RAG / Agent / 前端 | `../knowledge/`（L1-L7） |

**原则**：生命周期做骨架，技能做血肉，**VibeCut 做贯穿全场的活样本**。课程文档引用 `knowledge/` 的知识点，不复制内容。
